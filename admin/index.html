Locais a visitar · Descobrir o Gerês

Adiciona, edita e ordena os locais. O nome e a descrição são independentes para cada idioma; a fotografia e o Google Maps são comuns aos quatro. Podes escolher uma fotografia do computador (será enviada para a pasta assets quando publicares) ou indicar um endereço de imagem HTTPS. As imagens não devem conter dados privados.

Gastronomia · Restaurantes

Adiciona restaurantes com nome, fotografia, localidade, morada, direções Google Maps e telefone. Podes reordenar, eliminar e editar os nomes em quatro idiomas.

Experiências · Atividades

Publicar alterações

Para publicar, cria um token de acesso pessoal de âmbito limitado no GitHub, com acesso apenas ao repositório casinha-daldeia e permissão Contents: Read and write. Introduz o token apenas nesta sessão. Nunca o coloques no repositório nem o envies a ninguém. A publicação atualiza o ficheiro content.json.
